NETHACK(6)                       게임 매뉴얼                       NETHACK(6)



이름
       nethack - 위협의 미로 탐험

개요
       nethack [ -d|--directory 디렉토리 ] [ -w|--windowtype 인터페이스 ]
       [ --nethackrc:RC-파일 | --no-nethackrc ] [ -n ] [ -dec | -ibm ]
       [ -u 플레이어이름 ] [ -X | -D ] [ -p 직업 ] [ -r 종족 ] [ -@ ]

       또한 [ -A|-Arc | -B|-Bar | -C|-Cav | -H|-Hea | -K|-Kni | -M|-Mon |
       -P|-Pri | -R|-Rog | -Ran | -S|-Sam | -T|-Tou | -V|-Val | -W|-Wiz ]

       nethack [ -d|--directory 디렉토리 ] -s|--scores [ -v ]
       [ -p 직업 ] [ -r 종족 ] [ 플레이어이름들 ]

       nethack [ --usage | --help ] [ --showpaths ]
       [ --version[:copy|:dump|:show] ]

설명
       NetHack은 화면 지향 던전 앤 드래곤(tm) 스타일의 게임입니다. 표준
       tty 디스플레이와 명령 구조는 rogue를 닮았습니다.

       대부분의 플랫폼에서 다른 더 그래픽적인 디스플레이 옵션이 존재합니다.

       시작하려면 실제로 두 명령만 알면 됩니다. ? 명령은 사용 가능한 명령
       목록(및 기타 정보)을 제공하고, / 명령은 화면에서 보이는 것을
       식별합니다.

       게임에서 이기려면 (단순히 다른 사람의 최고 점수를 이기기 위해
       플레이하는 것과 달리) 던전 20층 아래 어딘가에 있는 옌도르의 아뮬렛을
       찾아 밖으로 가져와야 합니다. 이를 달성하는 사람은 거의 없습니다;
       대부분은 절대 못합니다. 이를 달성한 사람들은 영웅 중의 영웅으로
       역사에 남습니다 -- 그리고 나서 게임을 더 어렵게 만드는 방법을
       찾습니다. 이 게임이 너무 쉬워졌다면 가이드북의 행실(Conduct) 섹션을
       참조하세요.

       게임이 끝나면, 죽거나 포기하거나 동굴에서 탈출하든, NetHack은
       최고 점수자 목록의 (일부를) 보여줍니다. 점수는 행동의 많은 측면에
       기반하지만, 대략적인 추정치는 동굴에서 찾은 금화 양에 (실제) 경험치의
       4배를 더하여 얻습니다. 보석은 출구로 가져가면 많은 금화 가치가 있을
       수 있습니다. 죽으면 10% 페널티가 있습니다.

       NETHACKOPTIONS 환경 변수를 사용하여 많은 런타임 옵션을 초기화할 수
       있습니다. ? 명령은 이러한 옵션과 구문에 대한 설명을 제공합니다.
       (-dec 및 -ibm 명령줄 옵션은 상호 배타적이며 거기에 설명된
       decgraphics 및 ibmgraphics 런타임 옵션과 동등하며, 여러 유형의
       터미널을 지원하는 시스템에서 편의를 위해 제공됩니다.)

       옵션 목록이 매우 길 수 있으므로, 옵션은 구성 파일에도 포함될 수
       있습니다. 기본값은 UNIX 시스템(linux, NetBSD, macOS와 같은 파생
       시스템 포함)에서 홈 디렉토리에 있으며 .nethackrc라는 이름입니다.
       Windows에서 이름도 .nethackrc이지만 위치가 다를 수 있습니다
       (아래 --showpaths 참조). 다른 시스템에서는 기본값이 다를 수 있으며,
       가능하면 NetHack.cnf입니다. MS-DOS에서 이름은 NetHack 디렉토리의
       defaults.nh이고, VMS|OpenVMS에서는 홈 디렉토리의 nethack.ini입니다.
       기본 구성 파일은 --nethackrc:rc-file 명령줄 옵션을 통해 또는
       NETHACKOPTIONS를 @ 문자 다음에 경로와 파일명으로 구성된 문자열로
       설정하여 재정의할 수 있습니다.

       -u 플레이어이름 옵션은 "당신은 누구입니까?"라는 질문에 대한 답을
       제공합니다. 옵션이나 구성 파일, USER, LOGNAME, 또는 getlogin()의
       이름을 재정의합니다. 이 중 어느 것도 유용한 이름을 제공하지 않으면
       플레이어에게 물어봅니다. 플레이어 이름(uid와 함께)은 저장 파일을
       식별하는 데 사용되므로, 다른 이름으로 여러 저장 게임을 가질 수
       있습니다. 반대로, 저장된 게임을 복원하려면 적절한 플레이어 이름을
       사용해야 합니다.

       플레이어이름 접미사를 사용하여 캐릭터의 직업, 종족, 성향 및/또는
       성별을 지정할 수 있습니다. 접미사를 포함한 플레이어이름의 전체
       구문은 "name-ppp-rrr-aaa-ggg"입니다. "ppp"는 직업의 처음 세 글자
       이상입니다 (별도의 -p profession 옵션으로도 지정 가능). "rrr"은
       캐릭터 종족의 처음 세 글자 이상입니다 (별도의 -r race 옵션으로도
       지정 가능). "aaa"는 캐릭터 성향의 처음 세 글자 이상이고, "ggg"는
       캐릭터 성별의 처음 세 글자 이상입니다. 접미사의 어느 부분이든
       생략할 수 있습니다.

       -p 직업은 캐릭터 직업(역할이라고도 함)을 결정하는 데 사용할 수
       있습니다. 캐릭터 역할의 남성 또는 여성 이름이나 역할의 처음 세 글자를
       약어로 지정할 수 있습니다.

       마찬가지로, -r 종족은 종족 선택을 명시적으로 요청하는 데 사용할 수
       있습니다.

       역할 선택을 위한 -A|-Arc | -B|-Bar | -C|-Cav | -H|-Hea | -K|-Kni |
       -M|-Mon | -P|-Pri | -R|-Rog | -Ran | -S|-Sam | -T|-Tou | -V|-Val |
       -W|-Wiz 옵션은 프로그램의 이전 버전과의 호환성을 위해 유지됩니다.
       상호 배타적이며 단일 문자 형식은 대문자여야 합니다. Ranger는
       -R이 이미 Rogue 역할에 사용되므로 단일 문자 선택이 없습니다.

       -@ 는 nethack에게 프롬프트 없이 생략된 특성(직업/역할, 종족, 성별,
       성향)을 무작위로 선택하라고 합니다. 그렇지 않으면 이러한 특성을
       생략하면 게임 시작 중에 정보를 묻게 됩니다.

       -n 옵션은 게임 관리자의 뉴스 출력을 억제합니다.

       -X 옵션은 특별한 비점수 발견 모드(탐험 모드라고도 함)로 게임을
       시작합니다. -D는 플레이어가 허용되면 캐릭터 이름을 "wizard"로
       변경한 후 디버그 모드(마법사 모드라고도 함)로 게임을 시작합니다.
       그렇지 않으면 -X로 전환합니다. 디버그 모드 사용 권한 제어는
       nethack의 sysconf 파일의 "WIZARDS=" 줄을 통해 수행됩니다.

       -d 또는 --directory 옵션은 나타나면 첫 번째 인자여야 하며,
       플레이그라운드로 사용할 디렉토리를 제공합니다. NETHACKDIR, HACKDIR,
       또는 컴파일 중 게임 관리자가 지정한 디렉토리(일반적으로
       /usr/games/lib/nethackdir)의 값을 재정의합니다. 이 옵션은 일반적으로
       게임 관리자에게만 유용합니다. 플레이그라운드에는 도움말 파일,
       최고 점수자 목록, 게임이 저장되는 save 하위 디렉토리와 같은 여러
       보조 파일이 포함되어야 합니다.

       -w 또는 --windowtype 인터페이스 옵션은 프로그램이 둘 이상의 지원으로
       빌드된 경우 사용할 인터페이스를 지정하는 데 사용할 수 있습니다.
       명령줄에서 값을 지정하면 런타임 구성 파일에 지정된 값을 재정의합니다.
       NetHack의 #version 명령은 사용 가능한 인터페이스를 표시합니다.

       --nethackrc:RC-파일 옵션은 기본 런타임 구성 파일(일반적으로
       ~/.nethackrc) 대신 RC-파일을 사용하고, --no-nethackrc 옵션은
       런타임 구성 파일을 건너뛰는 데 사용할 수 있습니다.

       일부 옵션은 피드백을 제공한 다음 게임을 플레이하지 않고 종료합니다:

       -s 또는 --scores 옵션만으로 현재 버전의 점수 목록을 출력합니다.
       바로 뒤에 -v가 오면 점수 파일에 있는 모든 버전을 보고합니다.
       '-s|-s -v' 뒤에 -p 직업 및 -r 종족 인자를 붙여 특정 역할과 종족의
       점수만 출력할 수도 있습니다. 둘 다 여러 번 지정하여 둘 이상의 역할
       또는 종족을 포함할 수 있습니다. 둘 다 지정되면 역할이나 종족
       (또는 둘 다)과 일치하는 점수 항목이 인쇄됩니다. '-s|-s -v' 뒤에
       하나 이상의 플레이어 이름을 붙여 해당 플레이어의 점수를 출력하거나,
       'all'로 모든 점수를 출력하거나, 숫자로 해당 수의 최고 점수를
       출력할 수 있습니다.

       --version 또는 --version:show는 NetHack이 버전 번호, 소스 코드에서
       프로그램이 빌드된 날짜와 시간, 그리고 해당 소스 코드에 대한
       보조 정보를 표시한 다음 종료하게 합니다. --version:copy 변형은
       버전 정보를 표시하면서 클립보드에 복사합니다. --version:dump는
       저장 파일이나 본즈 파일이 프로그램과 호환되는지 확인할 때 사용되는
       대부분의 데이터를 표시합니다.

       --showpaths는 NetHack이 다양한 파일을 어디서 찾을 것으로 예상하는지
       표시합니다. 무엇보다도 플레이어의 런타임 구성 파일의 경로와 이름을
       표시합니다.

       --usage 또는 --help는 이 매뉴얼 페이지와 유사한 정보를 표시한 다음
       종료합니다. 한 페이지씩 읽으려면 'nethack --usage | more'를 사용하세요.

파일
       런타임 구성 옵션은 위에서 논의되었으며 플랫폼 특정 위치의 플랫폼
       특정 이름을 사용합니다. Unix의 경우 이름은 사용자 홈 디렉토리의
       '.nethackrc'입니다.

       다른 모든 파일은 플레이그라운드 디렉토리, 일반적으로
       /usr/games/lib/nethackdir에 있습니다. 컴파일 중 DLB가 정의되면
       데이터 파일과 특수 레벨은 개별 파일 대신 일반적으로 nhdat이라는
       더 큰 파일 안에 있습니다.

       nethack                     프로그램 자체.
       Guidebook | Guidebook.txt   NetHack 사용자 매뉴얼.
       data, oracles, rumors       NetHack이 사용하는 데이터 파일.
       bogusmon                    또 다른 데이터 파일.
       engrave, epitaph, tribute   더 많은 데이터 파일.
       symbols                     몬스터, 물건, 맵 기능 표시 방법에 대한
                                   사양 세트를 보유한 데이터 파일.
       options                     빌드 시 옵션 설정 설명이 포함된 데이터 파일.
       help, hh, cmdhelp           도움말 데이터 파일. ('cmdhelp'는 구식)
       opthelp, optmenu, wizhelp   더 많은 도움말 데이터 파일.
       keyhelp, usagehlp           더 많은 도움말 데이터 파일.
       *.lua                       미리 정의된 특수 레벨, 던전 제어,
                                   퀘스트 텍스트.
       history                     NetHack의 짧은 역사.
       license                     재배포 규칙.
       record                      최고 점수자 목록.
       logfile                     플레이된 게임의 확장 목록 (선택).
       xlogfile                    'logfile'의 더 자세한 버전 (선택).
       paniclog                    프로그램 실행 중 발견된 예외 조건 기록.
       save/                       저장된 게임을 포함하는 하위 디렉토리.
       sysconf                     시스템 전체 옵션.

환경
       USER or LOGNAME         로그인 이름.
       HOME                    홈 디렉토리.
       SHELL                   셸.
       TERM                    터미널 유형.
       HACKPAGER or PAGER      기본 페이저 대체.
       MAIL                    메일박스 파일.
       NETHACKDIR or HACKDIR   플레이그라운드.
       NETHACKOPTIONS          여러 NetHack 옵션을 미리 정의하는 문자열.
